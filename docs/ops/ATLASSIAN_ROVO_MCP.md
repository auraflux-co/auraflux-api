# Atlassian Rovo / Jira (MCP) — setup note

**Block 4 item #6** (“Rovo MCP setup”) is **not implemented in this repository**. It is configured in **Cursor / IDE**:

1. Open **Cursor Settings → MCP** (or the MCP panel).
2. Add your Atlassian-provided MCP server (or the official Jira/Confluence integration when available in your org).
3. Authenticate; scope to the projects you use for CWN / AuraFlux.

**Links:** [Atlassian MCP / Rovo documentation](https://www.atlassian.com) (search *Atlassian MCP server* in your org’s Confluence) — exact URLs are account-specific.

No `package.json` change is required for MCP; it is a client-side capability.
