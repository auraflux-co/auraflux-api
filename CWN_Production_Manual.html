ARCHITECTURE

PRODUCTION PIPELINE

Full agentic loop with QA gates at each handoff. Failed QA loops back to the responsible agent. All QA failures logged to Google Drive and locally.

Step 1 — Dashboard
Generate Video Request
User selects content type, streamers, clips-per-streamer. Dashboard fetches live clips via Twitch Helix API, resolves GQL MP4 URLs.
Step 2 — Gemini + Claude
Script Generation
Gemini watches all clips (3 waves, 10 clips each). Analyzes content. Claude writes full script using stored style fingerprint from reference video library. Structure: [Intro 2-3 sentences] → [CLIP] → [1-sentence reaction] → [2-sentence setup] → [CLIP] → [1-sentence reaction] → repeat.
🔍 QA: Claude checks structure, [CLIP PLAYS HERE] count, display names, word count
Step 3 — User Review
Script Review & Edit
Script displayed in dashboard editor. User reviews, edits inline, approves. Pronunciation library auto-applies phonetic substitutions before HeyGen send.
Step 4 — HeyGen API
Avatar Segment Generation
Each avatar text segment sent individually. Avatar ID: Bobby G (16:9 or 9:16). Voice: "cw" at 0.85 speed (reactions at 0.95). ~42 segments per Twitch compilation. Polls v1/video_status.get until COMPLETED. Cost: ~$0.004/sec.
🔍 QA: Gemini reviews 3-point sample (early/mid/late) — lip sync, ticker, freeze detection
Step 5 — FFmpeg Assembly
Video Assembly
1. Download all segments (avatar + source clips)
2. Re-resolve fresh GQL tokens for Twitch clips
3. Validate MP4 headers (skip CTYP/expired)
4. Normalize to TS: 1920×1080, 30fps, CFR, keyframe every 30 frames
5. Concat demuxer for 30+ segments (A/V sync guaranteed)
6. Bake ticker overlay (60s loop, CLIPZWORLD/NEWS/🔴LIVE)
7. Burn logo bug (top-right, 120px, 85% opacity)
8. ffprobe validation pass
🔍 QA: Gemini 3-point QA — early/mid/late 20s samples, freeze detection, ticker visible, score 0-100, threshold 60
Step 6 — Google Drive
Upload & Store
Auto-upload to Drive folder 1LJKU3DwQY4nwbLXBeNROpHc9o6tZbUyB. Sets public sharing. Failed QA reports saved as separate Drive documents. Local copy saved to ~/Downloads/output/.
Step 7 — Upload-Post API
Publish & Schedule
Upload-Post handles simultaneous distribution: YouTube (long form), TikTok, Instagram Reels, with scheduling based on content type and platform-specific optimal times.
⚠️
QA failures at any gate are logged to Google Drive under the same folder as video outputs. The failed step re-runs automatically until it passes or hits the max retry limit (3x).

[Streamer intro — 2-3 sentences. Sets up clip 1 with full context.] [beat] [CLIP PLAYS HERE] [beat] [ONE flat reaction sentence. Short. Deadpan.] [beat] [2-sentence setup for clip 2. Bridge from reaction. Context for clip 2.] [beat] [CLIP PLAYS HERE] [beat] [ONE flat reaction sentence. Short. Deadpan.] [beat] [2-sentence setup for clip 3. Bridge from reaction. Context for clip 3.] [beat] [CLIP PLAYS HERE] [beat] [ONE flat reaction sentence. Short. Deadpan.] [beat] Follow [ON-AIR NAME]. Link in description.

Key Rules

RuleDetail
Intro length2-3 sentences — LONGEST setup
Clip 2 & 3 setups2 sentences each — longer than reactions, shorter than intro
ReactionsEXACTLY 1 sentence. Flat. Can be non-sequitur. Never explain the clip.
[beat]3-second pause. Converted to "..." for HeyGen. Critical for delivery rhythm.

FFMPEG

ASSEMBLY PIPELINE

Normalization (per segment)

ffmpeg -i input -vf "scale=1920:1080:force_original_aspect_ratio=decrease, pad=1920:1080:(ow-iw)/2:(oh-ih)/2:color=black, fps=fps=30" -pix_fmt yuv420p -c:v libx264 -preset fast -crf 23 -g 30 -keyint_min 30 -sc_threshold 0 # keyframe every 1s -c:a aac -ar 44100 -ac 2 -af "aresample=async=1:min_hard_comp=0.100000:first_pts=0" -bsf:v h264_mp4toannexb -f mpegts output.ts

Concat (30+ segments)

# Concat demuxer — reliable A/V sync for large jobs ffmpeg -f concat -safe 0 -i list.txt -c:v libx264 -preset fast -crf 23 -c:a aac -ar 44100 -ac 2 -af aresample=async=1 -movflags +faststart output.mp4

Ticker Overlay

# 60s ticker capture at 15fps (900 frames) # Ticker URL: http://localhost:8765/cwn_twitch_ticker.html # Cached to ~/Downloads/tmp/ticker_twitch.mp4 # Delete cache to force recapture: rm ~/Downloads/tmp/ticker_twitch.mp4 ffmpeg -i video.mp4 -stream_loop -1 -i ticker.mp4 -t {duration + 2.0} # +2s buffer prevents outro truncation -filter_complex "[0:v][1:v]overlay=x=0:y=H-64:eof_action=repeat[vout]" -map [vout] -map 0:a -c:v libx264 -preset fast -c:a aac -movflags +faststart tickered.mp4

QUALITY

QA SYSTEM

Three-point Gemini QA runs after assembly. Samples at 10%, 50%, and 85% of the video. Each sample is 20 seconds.

QA Checklist by Sample Point

SampleChecks
EARLY (~10%)Lip sync, ticker visible, VIDEO FREEZE (critical), transitions clean, audio clear
MIDDLE (~50%)VIDEO FREEZE (critical), ticker still visible, video quality 1080p, avatar visible, audio clear
LATE (~85%)VIDEO FREEZE (critical), ticker still scrolling, outro ends cleanly, audio to end

Scoring

Pass threshold: 60/100 AND no freeze detected Freeze penalty: 20/100 per segment where freeze detected On freeze: 🚨 VIDEO FREEZE DETECTED — Drive upload BLOCKED On pass: ✅ QA passed — proceed to Drive upload
