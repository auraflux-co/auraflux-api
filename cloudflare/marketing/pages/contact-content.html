Frequently asked questions

What's the difference between Operate and Guided?
Both plans include the full AuraFlux platform. Operate is self-serve — you run everything yourself via API or the dashboard. Guided includes Collab-powered monitoring and guidance from the AuraFlux team.
How do credits work?
Each plan includes a monthly credit allowance. One credit = one short-form job. Long-form and multi-clip jobs use 2 credits. Unused credits roll over and additional packs are available any time.
Can I connect multiple social accounts?
Yes — you can connect YouTube, TikTok, Instagram, Twitch, and Kick. Each job can be targeted to one or more platforms simultaneously.
Do I need technical knowledge to use AuraFlux?
No. The dashboard guides you through every step. If you prefer direct API access, full developer documentation is available at app.auraflux.co/developer.
